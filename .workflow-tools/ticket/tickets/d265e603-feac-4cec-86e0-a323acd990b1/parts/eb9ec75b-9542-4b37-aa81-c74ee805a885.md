## Validation Criteria

**How to verify success:**
- [ ] `cargo test -p context-search` passes after each phase
- [ ] `cargo test -p context-trace` passes after Transition changes
- [ ] `cargo test -p context-insert` passes after Transition changes
- [ ] `npx vite build` succeeds with no TS errors
- [ ] Event chains in test output match canonical sequence from interview doc
- [ ] EdgeRef values in events contain real pattern_idx/sub_index data
- [ ] Query path events appear on separate path_id in log output
- [ ] VizPathGraph correctly tracks tentative vs confirmed root
- [ ] Visual check in log-viewer: tentative root has distinct styling
