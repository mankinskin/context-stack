## Requirements

1. Add a `benches/` directory to the kernel crate with at least one Criterion
   benchmark covering a real rendering/SVO hot path, following repository
   [benchmarks](../../workflow-tools/test/.agents/instructions/testing/benchmarks.instructions.md)
   and [calibration](../../workflow-tools/test/.agents/instructions/testing/benchmarks-criterion-calibration.instructions.md)
   conventions, with a bounded timeout per
   [benchmarks-timeout.instructions.md](../../workflow-tools/test/.agents/instructions/testing/benchmarks-timeout.instructions.md).
2. Wire an automated image-snapshot or Playwright-based capture harness to
   `sandbox-app` so a given voxel-mutation/interaction sequence produces a
   comparable artifact across runs.
3. Document the exact command(s) to run the benchmark suite and the capture
   harness so the restructure and defect-capture tickets can invoke them for
   before/after comparisons.
4. No implementation architecture is assumed for the harness beyond "produces
   comparable artifacts" — tool choice is left to the executing agent.
