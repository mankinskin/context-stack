## Acceptance Criteria

1. A `benches/` directory exists in the kernel crate with at least one
   Criterion benchmark that runs via a documented command.
2. An automated capture/visual-regression harness is wired to `sandbox-app`
   and produces comparable artifacts across repeated runs of the same
   interaction sequence.
3. Both the benchmark and harness invocation commands are documented so the
   restructure ticket (26105679) and the defect ticket (9d754852) can cite
   before/after evidence produced by them.
